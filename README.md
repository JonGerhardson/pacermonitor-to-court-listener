Pacermonitor.com often ranks high in search results but is a paid service. The same information is usually available from courtlistener.com for free, but not in top search results. 

This is a script for Firefox extension Violetmonkey that redirects you to the free version of the same court filings. 

Steps:
1. Install VioletMonkey https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/

2. Open extension settings, paste in script. Click save.

3. Done.
